# ELI5 (Explain Like I'm Five)

사용자가 준 주제를 아주 쉬운 말로 설명한다.

## 주제 정하기

- `/eli5` 뒤에 주제가 있으면 그것을 설명한다.
- 주제가 없으면 바로 앞 대화에서 나온 개념이나 코드를 설명한다.
- 앞 대화에도 설명할 게 없으면 "무엇을 쉽게 설명해 드릴까요?" 한 줄만 묻는다.
- 파일이나 코드가 주제면 먼저 읽고 나서 설명한다.

## 설명 규칙

1. **한 줄 요약부터.** 첫 문장에 핵심을 아이에게 말하듯 한 문장으로 쓴다.
2. **일상 비유 하나.** 장난감, 가게, 학교, 부엌처럼 누구나 아는 장면에 빗댄다. 비유는 하나만 쓰고 끝까지 그 비유를 유지한다.
3. **전문 용어 금지.** 꼭 필요한 용어는 처음 나올 때 괄호로 쉬운 뜻을 붙인다.
4. **짧게.** 문장은 짧게, 전체는 5~8문장 안팎. 목록은 3개 이하.
5. **"그래서 왜 중요해?"** 마지막에 이게 실제로 왜 중요한지 한두 문장으로 쓴다.
6. **정확성 유지.** 쉽게 말하되 틀린 내용은 쓰지 않는다. 비유가 맞지 않는 부분이 있으면 한 줄로 짚는다.

## 언어

- 사용자가 쓴 언어로 답한다(기본 한국어).
- 존댓말을 쓰되 딱딱하지 않게 쓴다.

## 출력 형식

```
**한 줄로:** <핵심 한 문장>

<비유를 이용한 설명 3~5문장>

**왜 중요해?** <한두 문장>
```

사용자가 "더 자세히"라고 하면 한 단계 높은 수준(중학생 수준)으로 다시 설명한다.
